# AI Learning Hub
**Learn AI. Explore Technology. Build the Future.**
## About the Project
AI Learning Hub is a beginner-friendly educational website designed to introduce students to Artificial Intelligence and its related fields.
## Objectives
- Introduce the fundamentals of Artificial Intelligence.
- Explain Machine Learning concepts.
- Explore Generative AI and popular AI tools.
- Provide information about AI career opportunities.
- Encourage students to explore emerging technologies.
## Technologies
- HTML5
- CSS3
- Git and GitHub
## Project Structure
The website consists of five main sections:
1. Home
2. AI Fundamentals
3. Machine Learning
4. Generative AI and AI Tools
5. AI Careers and Future
