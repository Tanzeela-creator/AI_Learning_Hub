What is Machine Learning?

Learn how machines become intelligent

Machine Learning is a branch of Artificial Intelligence that allows computers to learn from data instead of following only fixed instructions.

For example, when you watch videos on YouTube, the platform learns what you like and recommends similar videos.

ML

Learning from Data

LEARNING BASICS

Types of Machine Learning

There are three major ways in which machines learn.

01

Supervised Learning

The machine learns using labelled data, where the correct answers are already known.

Real-life example: Predicting house prices using previous house price records.
02

Unsupervised Learning

The machine finds hidden patterns and groups in data without given answers.

Real-life example: Grouping customers according to their shopping habits.
03

Reinforcement Learning

The machine learns through actions, rewards and penalties.

Real-life example: Teaching a robot to navigate a room.
IMPORTANT CONCEPTS

Popular ML Algorithms

Algorithms are methods that help computers learn patterns and make predictions.

Linear Regression

Predicts numerical values such as house prices based on different factors.

Decision Tree

Makes decisions by following a tree-like structure of questions and answers.

K-Nearest Neighbors

Predicts results by comparing new data with similar existing examples.

Random Forest

Combines multiple decision trees to produce predictions.
